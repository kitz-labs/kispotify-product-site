FAQ

Die wichtigsten Fragen.

Die Website zeigt das Produktprinzip und eine interaktive Demo. Das produktive Spotify-System läuft separat auf spotify.kitzlabs.ai.

Ist die Demo mit meinem Spotify-Konto verbunden?

Nein. Die Demo auf dieser Produktseite ist read-only und simuliert den Playlist-Flow im Browser. Sie erstellt oder verändert keine Spotify-Playlist.

Funktioniert der Agent nur für Afro House?

Nein. Die Produktlogik ist genre-unabhängig ausgelegt. Die Demo enthält unter anderem Afro House, Schlager, Rock, Drum & Bass, Jazz und Pop.

Was bedeutet Preview-First?

Der Agent zeigt zuerst eine validierte Vorschau. Erst nach Prüfung und Freigabe wird im Produktivsystem eine echte Playlist erstellt.

Kann das System für Gastro und Hotels eingesetzt werden?

Ja. Dayparts, Events, Auto-DJ, Playlist Library und wiederkehrende Automationen sind genau für solche operativen Musik-Workflows relevant.

Kann das System erweitert werden?

Ja. Die Architektur ist modular und unterstützt zusätzliche Apps, APIs, Agenten, Datenquellen und Automations-Workflows.
