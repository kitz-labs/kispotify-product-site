# KI Spotify Product Site

Separate Produkt-Landingpage für den bestehenden Spotify AI Agent.

## Live-Ziel
- Domain: https://kispotify.kitzlabs.ai/
- Produktiv-App: https://spotify.kitzlabs.ai/
- Typ: statische, eigenständige HTML-Landingpage
- Design: Dark Premium / Sora / #080908 / AI-Kitz Rot / Spotify-Grün
- Abhängigkeiten: nur Google Fonts; kein Build-System

## Inhalt
- Produkt-Erklärung
- interaktiver Browser-Mockup
- Multi-Genre-Demo
- Preview-First Flow
- Auto-DJ
- Event Radar
- Playlist Library
- Telegram / API Integrationen
- Responsive Mobile Layout
- Live-Health-Indikator zur bestehenden Spotify-App

## Safety
Diese Seite ist getrennt vom produktiven Spotify-Agent. Sie schreibt keine Playlist-Daten und greift nur lesend auf den öffentlichen Health-Endpunkt zu.

## Deployment
Nginx kann den Projektordner direkt als statische Site ausliefern.
